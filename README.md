# BasicFamily via EMFular

This repository shows how to replay and enhance the famous [starter and compartements tutorial of Sirius](https://wiki.eclipse.org/Sirius/Tutorials/BasicFamily) using our web-native [EMFular ecosystem](https://github.com/softlang/EMFular).

To explore the outcome, visit our gh-pages deployed [live version](https://emfular-demos.github.io/basicfamily-ge/).
